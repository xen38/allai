Allai

Open-source AI agent for Android, native and Opencode-inspired.

What is Allai?

Allai is an open-source AI agent built native for Android. Inspired by Opencode, it runs entirely on your device with an embedded terminal, an MCP/plugin system to control other apps, and an LLM-driven agent loop.

Features

✓ Compose-based chat UI
✓ Embedded shell terminal (sh -c)
✓ MCP client (JSON-RPC over stdio)
✓ Phone plugins: contacts, SMS, app launcher
✓ OpenAI-compatible LLM client
✓ MIT licensed

Quick start

Open the project in Android Studio and build:

./gradlew assembleDebug
./gradlew installDebug

Release bundle (signed):

./gradlew bundleRelease
